# Visual direction: distinct but useful

## Pick an art direction grounded in the product

Avoid choosing a trendy style independently of audience or task. Map audience → environment → primary action → emotional tone:
- Internal operations: dependable, crisp, neutral, fast, information-first.
- Retail on handheld: direct, friendly, energetic yet calm; clear buy/return/status actions.
- Desktop power tools: efficient, stable, system-native sensibility, minimal ornamental motion.
- Marketing sites: may justify expressive typography, imagery, asymmetry; don't apply those defaults to finance/inventory tables.

Create a consistent *visual personality*: choose a single defining trait (e.g., color accent on section headings, elegant typography, deliberate grid rhythm). More is not necessarily better; selective restraint is often more professional.

## Design decisions that visually matter most

1. **Composition:** controls form groups representing tasks, strong scan path, clear dominant action.
2. **Typography:** readable Vietnamese accents, appropriate weight hierarchy and tabular numeric treatment.
3. **Whitespace:** breathing room around sections, less between related label/value or control groups; denser views can still be elegant.
4. **Colors:** hue relationships and state semantics, not random palette splashes.
5. **Craft:** aligned labels, polished borders, focus, shadows used for meaningful elevation, coherent icons.
6. **Content honesty:** real labels, statuses, truncation, edge cases; data complexity should not be disguised.

## Spot generic AI patterns

Review, not automatic rejection:
- Almost every section is wrapped in another rounded card.
- Large purple/blue gradients with white hero text appear inside back-office apps.
- Same-sized icons followed by paragraphs on every tile; no clear information hierarchy.
- Primary buttons repeated in many unrelated places, competing for attention.
- Decorative glass, glows or random floating elements obscure dense information.
- Redundant badges, shadows or oversized rounded corners make serious apps toy-like.
- Screen appears aesthetic on empty sample data but breaks with 40 rows or Vietnamese labels.

Replace with intent: page + workspace canvas, correctly grouped surfaces, typographic hierarchy, meaningful data views, tighter primary flow, restrained accent.

## When the existing design is already good

Preserve its visual identity; improve one weak area instead of introducing a competing style. Prefer 3 high-impact edits to 30 minor decorative tweaks.
