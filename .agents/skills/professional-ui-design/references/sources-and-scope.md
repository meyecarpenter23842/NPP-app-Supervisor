# Provenance and scope

This is an **original consolidated ChatGPT skill**, independently written as a practical professional UI design workflow. It is **not a byte-for-byte redistribution**, direct installation, execution or replacement for any of the upstream repositories listed below. It contains no copied upstream scripts, datasets, automated browser tools, or font files.

Inspiration and optional upstream tools:
- Impeccable by Paul Bakaus (Apache-2.0): https://github.com/pbakaus/impeccable — visual critique, style polish and avoidance of generic AI design.
- UI UX Pro Max by Next Level Builder (MIT): https://github.com/nextlevelbuilder/ui-ux-pro-max-skill — structured palettes, typography, design systems, and component thinking.
- Anthropic Frontend Design: https://github.com/anthropics/skills/tree/main/skills/frontend-design — intentional aesthetic direction. The original skill has its own license terms; no text from its instructions is incorporated here.
- OpenAI skills packaging reference: https://developers.openai.com/api/docs/guides/tools-skills

Tools and limits: ChatGPT must separately have access to repo/files, image viewer, browser/Playwright and write privileges when applicable. Loading this skill does not install the original CLI tools or grant those permissions. No third-party dependency is bundled or auto-executed.

Version: 1.0.0 | Language: English instructions + Vietnamese usage prompts.
